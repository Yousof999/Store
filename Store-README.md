# 🛒 Store | React E-Commerce Storefront

A fully responsive e-commerce storefront built with **React**, delivering a smooth and fast shopping browsing experience powered by live data from a REST API.

🔗 **Live Demo:** [store-ivory-nine.vercel.app](https://store-ivory-nine.vercel.app/)

---

## ✨ Overview

Store is a front-end e-commerce application that simulates a real online shop. It dynamically fetches product data from an external API and renders it into a clean, organized, and fully responsive product catalog — built to feel fast, modern, and intuitive on any device.

## 🚀 Key Features

- **Dynamic Product Listings** — Products are fetched live from a REST API, not hardcoded, so the catalog reflects real, up-to-date data.
- **State Management with React Hooks** — Application state (product data, loading states, user interactions) is handled cleanly using `useState`.
- **Client-Side Navigation** — Implemented with **React Router**, allowing seamless transitions between product listings and individual product detail views without full page reloads.
- **Component-Based Architecture** — The UI is broken into small, reusable, presentational components, making the codebase easy to read, maintain, and extend.
- **Fully Responsive Design** — Optimized layout and interactions across mobile, tablet, and desktop screen sizes.

## 🛠️ Built With

- React.js
- React Router
- JavaScript (ES6+)
- CSS3 (Responsive Design)
- REST API Integration

## 📂 Project Structure Highlights

The project follows a component-driven structure, separating logic (data fetching, state) from presentation (UI components), which keeps the codebase scalable and easy to build on.

- Managing multiple pieces of UI state cleanly with hooks
- Structuring multi-view React apps using React Router
